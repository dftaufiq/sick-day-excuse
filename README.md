A small Python program that writes a one-line sick-day excuse, under 200 characters, to /output/entry.txt. The line is fixed and deterministic — the same 170-character line every run: a neighbour's parrot learned to imitate the alarm clock, so the sender has been up since 3am answering a bird.

## Run it

```sh
python3 main.py
```
